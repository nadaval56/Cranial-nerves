# עצבי הגולגולת

אתר לימודי בעברית על 12 זוגות העצבים הקרניאליים: מפה אינטראקטיבית של גזע המוח, עמוד מפורט לכל עצב, הבדיקה הנוירולוגית, שישה סימולטורים ומבחן עצמי. ההנחיות המלאות ב-[`CLAUDE.md`](./CLAUDE.md).

## הרצה

```bash
npm install
npm run dev        # שרת פיתוח
npm run build      # בדיקת תוכן + build ל-dist/
npm run preview    # הצגת ה-build
```

התלות היחידה בזמן פיתוח היא [Vite](https://vite.dev). הגופן (Heebo) מוגש מהאתר עצמו.

## מה יש באתר

- **עמוד הבית** — מפת גזע המוח: לוחצים על עצב ורואים מה הוא עושה.
- **העצבים** — 12 עמודים (`nerve-<id>.html`, נוצרים ב-build), עם שאלת "נסו קודם", מסלול, בדיקה, פגיעה ועובדות; ורשימה עם סינון וטבלה.
- **היסודות** — גזע המוח, סוגי עצבים, נוירון עליון ותחתון, פאראסימפתטי, פתחים, דרכי זכירה.
- **הבדיקה** — בדיקת העצבים צעד אחר צעד, וטבלת רפלקסים.
- **המעבדה** — תנועות העיניים (III/IV/VI), רפלקס האישון, מסלול הראייה, עצב הפנים (היקפי מול מרכזי), בסיס הגולגולת, מבחן עצמי.
- **היסטוריה** — מגלנוס ועד היום.
